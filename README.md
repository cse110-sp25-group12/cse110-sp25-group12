# cse110-sp25-group12

## Introduction

This repository contains **JobTracker**, a full-stack application built for the Software Engineering course **CSE110** at UC San Diego. Our team of **10 students** collaborated over **four** Agile sprints - using sprint planning, daily stand-ups, code reviews, CI/CD pipelines, and retrospectives—to design, implement, test, and document this project.  


**Live Application**: [JobTrack on Netlify](https://lighthearted-brioche-4c7d61.netlify.app)

**JS Documentation**: [Github Pages](https://cse110-sp25-group12.github.io/cse110-sp25-group12/)

# Getting Started (with VSCode)

1. Clone the repository onto your computer with ```git clone <repo-url>```
2. Navigate to and open up ```source/index.html```
3. Install the Live Server extension linked [here](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
4. Start the Live Server. The app will now automatically launch in the browser.

* To get a more in depth understanding of the project and how to make contributions, check out [onboard.md](onboard.md) and [HOW-TO-CONTRIBUTE.md](HOW-TO-CONTRIBUTE.md)
